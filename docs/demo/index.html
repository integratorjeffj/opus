Opus is a demonstration build.

A PayPal activity export contains real buyer names, email addresses and transaction IDs. A catalog folder contains copyrighted engravings. Neither belongs in a demo.

Before you continue, confirm that the files you are about to load are fictional, redacted, or otherwise non-sensitive, and that you have the right to use any music you point Opus at.

The notice is merged into the page content stream rather than added as an annotation, so it is not a separate object a reader can select and delete. The issued file opens and prints with no password; editing, text extraction and page re-assembly are blocked with AES-256.

What this leaves out

Delivery. Opus stamps, locks and logs; getting the files to the buyer is still a human attaching them to a reply. That is the next phase, and the ledger is what will record the send.
